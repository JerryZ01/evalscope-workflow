# 用户指南

## 快速开始

### 1. 启动服务

```bash
# 后端
cd backend
python -m uvicorn main:app --host 0.0.0.0 --port 8000

# 前端（另一个终端）
cd frontend
npm install
npm run dev
```

访问 `http://localhost:5173`

### 2. 创建任务

1. 点击左侧菜单「任务列表」
2. 点击右上角「创建任务」
3. **Step 1 - 选择模型**：选择已管理模型或手动输入模型名称、类型、API URL
4. **Step 2 - 选择数据集**：搜索并勾选数据集（如 gsm8k）
5. **Step 3 - 配置参数**：设置评测引擎、样本数限制、生成参数
6. **Step 4 - 确认**：填写任务名称，提交后自动启动

### 3. 任务操作

| 状态 | 可用操作 |
|------|----------|
| 待执行 | 启动 / 编辑参数 / 删除 |
| 运行中 | 暂停 / 停止 / 停止并删除 |
| 已暂停 | 恢复 / 编辑参数 / 删除 |
| 已完成 | 编辑参数（保存并重新执行）/ 删除 |
| 失败/已取消 | 重试 / 编辑参数 / 删除 |

### 4. 查看结果

任务完成后，进入详情页查看：
- **总体评分**：右上角圆形进度显示最终得分
- **指标雷达图**：各评测指标的得分分布
- **类别分布**：不同类别下的得分
- **AI 分析报告**：自动生成的分析文本
- **可视化报告**：完整的 Plotly 交互图表（支持缩放、悬停）
- **评测日志**：完整执行日志

### 5. 编辑参数并重新执行

已完成的任务可在详情页点击「任务配置」卡片右上角的「编辑参数」按钮，弹出编辑弹窗：
- 修改模型、数据集、生成参数
- 点击「仅保存」仅更新配置
- 点击「保存并重新执行」更新配置并立即重新运行

## 功能说明

### AI 助手

点击左侧「AI 助手」进入对话页面，AI 助手可以：
- **回答平台使用问题**：如何创建任务、配置模型、查看结果等
- **查询实际数据**：通过 Function Calling 自动查询评测任务、结果、数据集等平台数据
- **分析评测结果**：直接询问某个任务的评测结果，AI 会自动获取并分析

**支持的查询场景**：

| 说话方式 | AI 行为 |
|---------|---------|
| "我最近跑了哪些评测？" | 查询任务列表 |
| "分析一下'日志显示测试'的结果" | 按名称查找任务并获取评测结果 |
| "对比 qwen 和 gpt 在 mmlu 上的表现" | 对比多个模型的评测结果 |
| "有哪些数学类数据集？" | 搜索数据集目录 |
| "平台整体情况怎么样？" | 查看仪表盘统计 |
| "你好" | 直接回答，不调工具 |

**会话管理**：
- 左侧会话列表支持新建、切换、删除对话
- 对话历史自动保存到浏览器，刷新页面不丢失
- 点击「新对话」开始新的对话，之前的会话保留在列表中
- 会话标题自动从第一条消息推断

**注意事项**：
- AI 助手需要先在模型管理中配置 OpenAI 兼容模型才能使用
- 工具查询期间会显示"正在查询..."提示，请耐心等待
- AI 只能查询数据，不能创建任务或启动评测

### 数据集目录（Benchmark 库）

点击左侧「目录」浏览：
- **数据集**：所有可用评测基准（GSM8K、MMLU、BBH 等），描述已显示中文
- **模型类型**：支持的模型接入方式（OpenAI API、LLM Checkpoint 等）
- **指标**：各数据集对应的评测指标

点击数据集卡片的「查看」按钮可展开详情抽屉，查看中文描述（Markdown 格式渲染）、标签、Subset 列表、指标等信息。

左侧筛选面板支持按能力维度、任务类型、模态、执行特性四个维度筛选数据集。

### 模型管理

点击左侧「模型管理」：
- 保存常用的 API 凭证和默认参数
- 设为默认模型（创建任务时自动填充）
- 创建/编辑/删除模型配置

### 系统设置

点击左侧「设置」：
- 修改输出目录（评测结果存放位置）
- 开关缓存使用、调试模式

### 实时日志

运行中的任务每 3 秒自动刷新日志，前端通过 SSE 实时接收进度更新。

### HTML 报告

评测完成后生成的交互式 HTML 报告直接内嵌在任务详情页中，支持拖动图表区域、悬停查看详细数据。

## 常见问题

**Q: 任务卡在 90% 怎么办？**
检查日志中的错误信息。常见原因：API Key 失效、网络超时、模型不支持该数据集。

**Q: 为什么分数为 0？**
可能是 API 调用失败或模型返回格式不正确。检查日志和错误信息。

**Q: 如何使用本地模型？**
选择模型类型 `LLM Checkpoint`，模型名称填写 ModelScope 上的 checkpoint 路径或 HuggingFace 模型名。

**Q: 报告图表不显示？**
确保后端服务正常运行，前端能访问 `/api/eval/report/{taskId}`。Plotly.js 从后端 `/static` 路由加载。

**Q: 已完成的任务如何重新运行？**
在任务详情页点击「任务配置」→「编辑参数」→「保存并重新执行」。

**Q: AI 助手说"未找到可用模型"？**
需要先在「模型管理」中添加一个 OpenAI 兼容的模型配置（填写 API URL 和 API Key），AI 助手才能工作。

**Q: AI 助手查询数据时反复失败怎么办？**
AI 助手有防死循环机制，连续失败时会自动停止查询。建议明确提供任务 ID 或精确名称，帮助 AI 准确找到数据。
